# KitsuneStacks

## 7 Days to Die Modlet

Increases the stack sizes on most items, so you can carry and store far more
resources, ammo, food, and more. Intended for players who would rather not
worry about storage space.

**Verified for 7 Days to Die V3.0 (Dead Hot Summer).** All patches target
vanilla item names and the `Stacknumber` property, which are unchanged in V3.0;
the modlet loads and applies cleanly. It is XPath-only (no DLL), so any unmatched
patch simply no-ops rather than causing errors.

### Install

Copy the `KitsuneStacks` folder into your `7 Days To Die/Mods/` directory and
restart the game. EAC does not need to be off (config-only modlet).
