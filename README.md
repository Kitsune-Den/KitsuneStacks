# KitsuneStacks

## 7 Days to Die Modlet

Increases the stack sizes on most items, so you can carry and store far more
resources, ammo, food, and more. Intended for players who would rather not
worry about storage space.

**Verified for 7 Days to Die V3.1 (Henpocalypse) and V3.2.** All patches target
vanilla item names and the `Stacknumber` property, which are unchanged; the
modlet loads and applies cleanly. The prefix wildcards automatically cover
V3.1's new chicken-farming items (dishes, feed, feathers, coop tools). It is
XPath-only (no DLL), so any unmatched patch simply no-ops rather than causing
errors. Note: V3.1's new Stack Size Multiplier sandbox option shares the same
30,000 cap this modlet already uses; the two coexist fine.

### Install

Copy the `KitsuneStacks` folder into your `7 Days To Die/Mods/` directory and
restart the game. EAC does not need to be off (config-only modlet).
